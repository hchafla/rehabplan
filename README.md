# RehabPlan

**La caja de herramientas del fisioterapeuta.**

RehabPlan es una aplicación web diseñada para reunir en un único lugar las herramientas que un fisioterapeuta utiliza en su práctica clínica diaria. Su objetivo es agilizar el trabajo, reducir tareas repetitivas y facilitar la creación de documentación profesional para los pacientes.

## Estado del proyecto

Actualmente, RehabPlan se encuentra en desarrollo y dispone de los siguientes módulos:

### ✅ Ejercicios

Crea planes de ejercicios personalizados de forma rápida e intuitiva.

Incluye:

- Biblioteca de ejercicios con imágenes.
- Organización por regiones anatómicas.
- Configuración de series, repeticiones o tiempo.
- Notas personalizadas para cada ejercicio.
- Generación automática de PDF profesional.
- Códigos QR con acceso directo a vídeos demostrativos.

### ✅ Plantillas

Guarda protocolos de tratamiento habituales para reutilizarlos con un solo clic.

Ideal para patologías o programas de ejercicios frecuentes.

## Filosofía

RehabPlan nace con una idea muy sencilla:

> Que el fisioterapeuta dedique menos tiempo al ordenador y más tiempo al paciente.

La aplicación busca ofrecer una experiencia rápida, limpia y sin distracciones, con herramientas realmente útiles para el día a día en consulta.
